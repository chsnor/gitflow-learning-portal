# GitFlow Visualizer — Learning Portal

เว็บพอร์ทัลเรียนรู้สำหรับพรีเซนต์โปรเจกต์ **git_flowcahrt** (Next.js) ของทีม 6 คน
ฝังโค้ดจริงทั้ง **19 ไฟล์** พร้อมบทวิเคราะห์รายไฟล์ครบทุกไฟล์

## โครงสร้างไฟล์ (UI v3)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | เชลล์หน้าเว็บ — Tailwind v4 browser CDN + `@theme` OKLCH tokens, sidebar rail + 2 code panes + Inspector |
| `style.css` | Design tokens (OKLCH) + คอมโพเนนต์ทั้งหมด + focus-visible + prefers-reduced-motion |
| `data-code.js` | โค้ดจริงทั้ง 19 ไฟล์ (`RAW_*` template literals) — **โหลดก่อนสุด** |
| `data-content.js` | ข้อมูลการสอน: `LOGICAL_STEPS`, `FILE_META` (lazy `initFileMeta()`), `FILE_GUIDES` (บทวิเคราะห์ครบ 19 ไฟล์), SIM/CICD/REDTEAM/QNA/QUIZ |
| `data-arch.js` | สถาปัตยกรรมเชิงลึก: `ARCH_LAYERS` (7 ชั้น), `LAYOUT_STACK` (5 ระดับ UI), `HIGHLIGHT_SYSTEM` (ทุกคลาสไฮไลต์), `RENDER_FUNCS` (10 ฟังก์ชันเรนเดอร์) |
| `data-defense.js` | `DEFENSE_DEEP` (11 คำถามลึก + ไลบรารี), `ROADMAP` (P0-P4), `PORTAL_QA` (คำถามเรื่องตัวพอร์ทัล) |
| `app.js` | Render + Interaction layer เท่านั้น (ไม่มีข้อมูลโค้ด) |

**ลำดับสคริปต์:** `data-code.js` → `data-content.js` → `app.js` (ใส่ `?v=N` กัน cache ทุกครั้งที่แก้)

## 6 มุมมอง

1. **เจาะสเต็ป** — โค้ดจริงคู่ขนาน (ซ้าย = งานคน 6, ขวา = โมดูลเพื่อน) + ไฮไลต์ตามสเต็ป + **คลิกบรรทัดไหนก็ได้ทั้ง 19 ไฟล์ เพื่อปักหมุดอ่านต่อ**
2. **ภาพรวม** — การ์ดสรุป 6 สเต็ป
3. **ซิมูเลเตอร์** — 10 จังหวะการไหลของข้อมูล + **การ์ดโค้ดจริงแบบ inline** (ระบุไฟล์ + บรรทัด ไฮไลต์บรรทัดเป้าหมาย) ไม่ต้องออกจากซิมูเลเตอร์
4. **CI/CD** — ถอดรหัส ci.yml (Targeted Test ด้วย Regex feat/person-X) + Dockerfile
5. **Red Team** — 6 จุดเสี่ยง + วิธีป้องกัน
6. **Q&A** — สคริปต์ตอบอาจารย์ 5 ข้อ + แบบทดสอบ 5 ข้อพร้อมเฉลย
7. **สถาปัตยกรรม** — 7 ชั้นงาน (ทุกชั้นมี input/output, ขั้นตอนพร้อมลิงก์บรรทัดจริง, เคสพลาด, จุดตัดสินใจ, สิ่งที่จะต่อยอด) + ตารางสแต็กเลเยอร์ UI + ตารางระบบไฮไลต์ + วิธีเรนเดอร์
8. **ป้องกันงาน** — 11 คำถามลึกพร้อมคำตอบยาว ไลบรารีที่เกี่ยวข้องพร้อมข้อแลกเปลี่ยน และแผนต่อยอด 5 เฟส

## Inspector (ตัวตรวจไฟล์) — จุดเด่น v3

- แผงล่างแสดงบทวิเคราะห์ของ **ไฟล์ที่เปิดอยู่ทั้งสอง pane — ครอบคลุมทั้ง 19 ไฟล์** (จาก `FILE_GUIDES`)
- แต่ละไฟล์มี: เจ้าของ + เทคโนโลยี + path + หน้าที่ + กลไกแยกบรรทัดจริง + จุดเชื่อมต่อ + แนวตอบอาจารย์
- Step dots 1-6 + ribbon (เป้าหมายสเต็ป + แนวพูด) อยู่หัวแผง, ย่อได้

## ซิมูเลเตอร์: โค้ดจริงแบบ inline (ไม่ต้องกระโดดออกจากซิมู)

- ทุกจังหวะแสดงการ์ดโค้ดจริงจากไฟล์ต้นฉบับ พร้อม **ชื่อไฟล์ + เลขบรรทัดเป้าหมาย** (เช่น `pipeline.ts · บรรทัด 301 · ช่วง 299-308`) และ path ของไฟล์
- บรรทัดเป้าหมายถูกไฮไลต์ พร้อม syntax highlighting เหมือนโหมดเจาะสเต็ป (กล่องสูงสุด 280px เลื่อนได้)
- บางจังหวะแสดงหลายไฟล์ เช่น จังหวะ 7 = `pipeline.ts` + `github.ts`, จังหวะ 8-9 = `parser.ts` / `generator.ts`
- ข้อมูลการ์ดทั้งหมดมาจาก `SIM_JUMPS[].snippets` ใน [data-content.js](data-content.js) · ฟังก์ชัน render อยู่ใน [app.js](app.js) (`simCodePanel`, `simSnippetBlock`)
- ปุ่ม "เปิดไฟล์เต็ม →" ยังอยู่ (ทางลัดไปโหมดเจาะสเต็ป) แต่ไม่บังคับแล้ว

## กดแล้วอ่านต่อ (Line Reader) — ครบ 19 ไฟล์ + ไฟล์ที่เกี่ยวข้อง

- **คลิกบรรทัดไหนก็ได้** ในทั้ง 2 pane (ไม่จำกัดแค่ pipeline.ts) → บรรทัดนั้นถูกไฮไลต์สีเหลือง และเปิดการ์ด **ตัวอ่านบรรทัด** มุมล่าง
- การ์ดแสดง: ชื่อไฟล์ · **บรรทัด N / ทั้งหมด** · เจ้าของไฟล์ · บรรทัดที่กดแบบเต็ม · บริบทรอบ ๆ ±8 บรรทัดพร้อม syntax highlighting · path ของไฟล์
- **ไฟล์ที่เกี่ยวข้องขึ้นมาครบ** ตามกราฟที่คำนวณจากโค้ดจริง (`FILE_GRAPH` — 251 ความสัมพันธ์จาก 19 ไฟล์ แบ่งเป็น `import` / `เรียกฟังก์ชัน` / `อ้าง path`) จัดกลุ่มเป็น
  - **↓ เรียกใช้** — ไฟล์ที่บรรทัดนี้เรียก (แสดงบรรทัดจุดประกาศ/นิยามในไฟล์ปลายทาง + หมายเหตุ "เรียกจากบรรทัด N")
  - **↑ ถูกเรียก** — ไฟล์ที่เรียกบรรทัดนี้ (พร้อมบรรทัดที่เรียก)
  - **⇄ ชั้นที่ 2** — ปุ่ม "ดูอีก N ไฟล์ (ชั้นที่ 2)" สำหรับไฟล์ที่เชื่อมต่อทางอ้อม
  - ถ้าบรรทัดที่กดไม่มีความสัมพันธ์ตรง ระบบจะแสดงความสัมพันธ์ทั้งไฟล์แทน
- ทุกการ์ดไฟล์ที่เกี่ยวข้องมีปุ่ม **"ดูโค้ดรอบบรรทัดนี้"** (ขยายโค้ดในตัวอ่าน) และ **"เปิดใน pane →"** (สลับแท็บไฟล์นั้น + ไฮไลต์บรรทัด โดยไม่ทิ้งตัวอ่าน)
- ตัวอ่านยึดฝั่ง **ตรงข้าม** กับไฟล์ที่กำลังอ่านเสมอ และเลื่อน pane ให้บรรทัดที่กดอยู่บนสุด เพื่อไม่ให้ถูกบัง
- ปุ่มลัดในการ์ด: **ไปสเต็ป N** / **ไปจังหวะซิมู N** (ถ้าบรรทัดนั้นอยู่ในช่วงที่เกี่ยวข้อง)
- `pipeline.ts` ยังคงพฤติกรรมเดิม: คลิกในช่วงสเต็ปจะกระโดดสเต็ปนั้นด้วย
- ฟังก์ชันอยู่ใน [app.js](app.js): `buildFileGraph`, `relationsFor`, `normalizeRelList`, `renderLineReader`, `relItemHTML`, `openRelated`, `toggleRel`, `toggleRelDepth`, `onCodeRowClick`, `pinLine`, `movePin`, `clearPinned`, `scrollPaneToPin`

## คีย์ลัด

- `A` / `←` สเต็ปก่อนหน้า · `D` / `→` สเต็ปถัดไป (ในซิมูควบคุมจังหวะซิมู)
- `↑` / `↓` อ่านต่อทีละบรรทัดจากบรรทัดที่ปักหมุด · `Shift` + `↑`/`↓` ขยับ 10 บรรทัด · `Esc` ปิดตัวอ่าน

## เปิดใช้งาน

- ดับเบิลคลิก `start-learning-portal.bat` หรือเปิด `index.html` ผ่าน local server
- เวอร์ชันออนไลน์: https://mali-gitflow-1645.netlify.app

## Deploy (Netlify)

```bash
NETLIFY_AUTH_TOKEN=<token> NETLIFY_SITE_ID=<site id> \
  npx netlify-cli deploy --prod --dir=_deploy
```

`_deploy/` ต้องมี: `index.html`, `style.css`, `app.js`, `data-code.js`, `data-content.js`, `favicon.ico`
