## สถาปัตยกรรมใหม่
- 3 คอลัมน์: `rail 248px | main 1fr | context 360px (xl)`
- **4 โหมด**: เจาะสเต็ป · ไทม์ไลน์ · ระบบ · ซ้อม (รวม 8 มุมมองเดิมเป็น section ของแต่ละโหมด — id เดิมทั้งหมดยังเรียกได้ผ่าน alias)
- **หัวใจ: `syncPaneChrome()`** = แหล่งความจริงเดียวของหัว pane → ชื่อไฟล์ / ป้ายเจ้าของ / ป้ายความสัมพันธ์ แยก 3 element ไม่เขียนทับกัน
- **รายการไฟล์ 19 ไฟล์** ย้ายไปอยู่ใน context rail (ค้นหาได้, จัดกลุ่มตามคน) แทนแท็บ
- ตัวอ่านบรรทัด → bottom sheet ใน flow (ไม่ลอยทับโค้ด) + ปุ่ม "เปิดใน pane" เมื่อไฟล์ที่ปักหมุดไม่ได้เปิดอยู่
- Token: `@theme` (Tailwind) เป็นแหล่งเดียว · `style.css` บริโภค `var(--color-*)`

## งาน
1. Tokens: ขยาย `@theme` + style.css กิน `var(--color-*)`
2. index.html: shell ใหม่ (Tailwind utilities) คง id เดิมทุกตัว
3. app.js: registry โหมด/เซกชัน + `syncPaneChrome()` + pane focus + รายการไฟล์ใน rail
4. ตัวอ่านบรรทัด + มือถือ + คีย์ลัด (1-4, `[`/`]`, `f`, Esc)
5. ตรวจ: spec review → quality review → เบราว์เซอร์จริง (1440/390) → console → regression → deploy
